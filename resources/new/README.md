# 英语拼块 · V10（咪咪主角款 Logo / 计时挑战 / 四阶段徽章）

保留 V9 的全部玩法：咪咪翻译官、词组发现、自由插入式词块拖放、实时对位、完整答案、衣柜、音效工作室、自定义 BGM 和可迁移学习存档。V10 将已确定的主角款品牌设计和计时玩法正式接入。

## 在电脑运行

1. 安装 Node.js 24 或更新版本。
2. 将本 ZIP 解压到一个新文件夹；进入包含 `package.json` 的目录。
3. 初次运行：`npm install`。
4. 输入 `npm run dev`，用浏览器打开终端显示的地址（通常是 `http://localhost:3000`）。以后启动只需执行 `npm run dev`。

## V10 新增：计时与挑战记录

- **何时开始？** 放入第一个词块或开始拖动词块后自动开始。打开其他菜单、提示弹窗或切到后台时暂停；返回游戏后继续。点击「下一关」或「重温」会开始新的一轮。
- **计时奖励**：≤1 分钟 +6 小鱼干；≤2 分钟 +4；≤3 分钟 +2；≤5 分钟 +1；超过 5 分钟没有速度加成，并由咪咪说一句吐槽（不反复刷屏）。这部分是**原有通关奖励之外的加成**。
- **防止重复刷鱼干**：同一关的速度奖金按照最高已解锁档位计算：第一次达标可以领取，之后刷新到更高档位只补差额。例如原来领了 2 分钟 +4，之后打破 1 分钟关口只再补 +2。
- **个人最佳**：每关都记录历史最佳时间、最近一次用时、独立完成次数。打破个人最佳，结算会显示奖杯；即使没有跨越奖励档位，也会庆祝你刷新纪录。
- **看完整答案不会刷计时奖**：本题使用完整答案后的通关不记为「独立完成」，不刷新个人纪录，也不会领速度加成。
- **存档**：计时记录直接保存在原学习档案中。导出「完整备份（含学习记录）」会一起带走计时纪录；导出「设置备份」则不会带走个人成绩。

## V10 新增：设计元素

- **A 款主角 Logo**：直接采用你选中的设计稿里的橘色咪咪+彩色拼块主角图标，替换侧边栏旧猫爪，并加入浏览器标签小图标；Logo 图片位于 `public/assets/brand-mimi-a.png`。
- **四阶段彩绘徽章**：初中基础（绿叶书本）、高中进阶（展翼小鹰）、大学英语（星光书卷）、考研冲刺（学士帽与金羽），用于关卡目录、侧边栏及学习档案。
- **计时条 UI**：奶油绿、金色奖章的四档奖励提示和实时秒表，最佳成绩在每关上方直接可见。

## 继承的 V9 操作

- **词块对位反馈**：直接放到某格，只要单词确实属于那个位置就变成深绿色，并显示「对位 n / 总数」。放错的位置仍是原色。对位按轨道格子的位置判断，不要求先放满左边。
- **语法提示**：按顺序解锁 3 级提示；全部解锁后出现「直接查看完整答案（放弃本题小鱼干）」；此操作不会扣掉已持有的小鱼干，但**本关通关奖励为 0**。可选择「按答案填入词块」，再点击「检查句子」，就能继续下一关。
- **关卡目录**：四阶段学习地图（初中基础、高中进阶、大学英语、考研冲刺）+ 关卡网格。当前 LEVEL 会被强调显示，手动选关会保存游标。
- **学习档案**：更新头像卡片、昵称编辑、阶段路线、学习指标，数据显示真实存档记录。
- **咪咪互动**：点猫咪发出「咪咪开心叫声」（除非关闭声音或静音该音效位）；拖动猫咪仍可移动。
- **导入备份**：换成屏幕中央的完整确认弹窗，明确区分完整备份与设置备份。

## 存档使用与保护

更新之前先在旧版「系统设置 → 保存与分享游戏数据」选择「导出完整备份（含学习记录）」。在 V10 使用「导入备份」，选择先前的 JSON 文件确认即可。游戏会刷新并还原设置、音乐与学习记录。

**导出设置备份（不含学习记录）** 只含主题、音效、装扮和自定义 BGM 等配置；导入它不会重置已有学习进度。文件内含曾成功保存的音频数据，传到别的电脑上也可以恢复音乐（缺失的原始音频无法凭名称再现）。

V8 学习进度若意外保存成第 1 关，V10 会尽可能根据**已通关的关卡 ID**，从第一个未完成位置继续。如果存档完全没有已完成记录，无法推断此前实际玩到了第几关，可从关卡目录手动选关，之后会记住位置。

## 验证

- `npm run lint`：TypeScript 类型检查
- `npm run test:timing`：四档奖励边界、同关防重复刷币、个人纪录、完整答案不计时、备份 JSON 兼容
- `node --experimental-strip-types tests/answer-and-progress-regression.mjs`：实时对位、重复词、自动填词、旧存档续关
- `node --experimental-strip-types tests/rail-state-regression.mjs`：拖放 500 轮及随机 5000 次稳定性测试
- `node --experimental-strip-types tests/phrase-matcher-regression.mjs`：相邻词组识别
- `node --experimental-strip-types tests/progress-regression.mjs`：进度迁移规则

注意：当前构建环境缺少 Vite 的本机 Rolldown 原生依赖，因此虽然类型检查及逻辑测试通过，尚未完成真实浏览器端到端交互测试；下载后运行时遇到问题可以继续根据具体操作定位。
