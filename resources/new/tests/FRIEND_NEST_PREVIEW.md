# 好友小窝界面验证

1. `npm run build`
2. `node tests/helpers/friend-nest-server.cjs`
3. `PLAYWRIGHT_MODULE=/path/to/playwright node tests/friend-nest-ui.cjs`

自动化测试专用服务只在临时目录建立独立 SQLite 数据库，不读取生产数据库或 `.env`，并禁用 AI 接口。测试账号注册、存档、有效题目完成、好友申请确认与恶作剧均通过真实服务端接口准备。加速答题等待仅在此工具内设置。

仅在自动化测试专用服务中，访问 `/preview/friends` 体验主账号，`/preview/friends/1` 体验其好友，`/preview/friends/2` 体验申请者。自动登录只存在于独立预览工具，正式服务没有这些路由。请勿在此共享体验环境填写私人资料。关闭进程后清理数据；再次启动重建体验数据。端口默认 4174，允许 `EB_PREVIEW_PORT` 指定。

浏览器测试会改变测试好友关系和道具余额，每次完整测试前重新启动工具。测试覆盖 320 / 390 / 1366 宽度、插画加载、申请输入验证与关闭、两个详情入口、只读衣柜及动态、取消删除、接受申请、对决选择、真实道具发送与处理。底层每日限制、隐私和反击由 `npm run test:social` 验证。

正式数据库结构和 API 没有变更。本次只更新页面组件、样式、静态插画及现有编辑档案入口。

用户预览使用 `node tools/preview-friend-nest.cjs`，不创建任何账号、好友、学习记录或恶作剧；用户自行注册并产生交互。旧版预览的预置账号本机数据会在预览入口清理，其他用户数据不会被清理。自动化测试专用服务不得发布给用户。
